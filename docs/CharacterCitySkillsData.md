* 출처: `https://nte.inven.co.kr/db/esper`
* 비고: 사이트에 표기된 원문(오탈자 포함) 그대로 수록함

## 0. 참고
- `점장 특제`, 식재료 소모속도 효과는 계산에서 제외 (적용 규칙은 `gameLogicData.md`의 「도시 스킬 적용 규칙」 참고)
- 형식: `캐릭터 — 스킬명 (판매가 합연산, 판매가 곱연산, 유동인구 합연산, 유동인구 곱연산)`
    - 레벨 5(누적) 기준 최대값
    - 조건부 스킬의 경우 범위표현 (조건 미충족 ~ 조건 모두 충족)
    - 판매가 합연산: 폰즈 / 판매가 곱연산: % / 유동인구 합연산: P / 유동인구 곱연산: %
