# 음식 데이터

* 출처: 게임 내에서 직접 적음

## 참고
- 음식 형식: `음식명: 가격(태그)(재료1, 재료2, ...)`
    - 음식당 태그는 하나만 가질 수 있음
- 트렌드는 태그 트렌드, 재료 트렌드가 존재하며 

## 음식
* 구운 코코넛 라테: 10.2(음료)(커피 원두, 코코넛)
* 아이스 모카: 10.6(음료)(커피 원두, 코코아 가루)
* 애플파이: 11(디저트)(밀가루, 사과)
* 에그토마토 크루아상: 11.4(메인 메뉴)(밀가루, 사과, 날달걀)
* 참치 샌드위치: 11.8(메인 메뉴)(밀가루, 상추, 해수어)
* 골든 앰버: 12.2(음료)(커피 원두, 우유, 별사탕, 오렌지)
* 말차 용암 무스케이크: 12.6(디저트)(밀가루, 우유, 말차 가루)
* 생초콜릿 라테: 13(음료)(커피 원두, 우유, 휘핑크림, 코코아 가루)
* 두툼하고 신선한 소고기 샌드위치: 13.5(메인 메뉴)(밀가루, 신선한 소고기, 상추, 단단한 버터)
* 앙버터 크루아상: 14(메인 메뉴)(밀가루, 단단한 버터, 팥)
* 딸기 스윗박스: 14.5(디저트)(우유, 딸기, 휘핑크림)
* 뜨거운 오렌지 커피: 15(음료)(커피 원두, 오렌지, 사과)
* 돈가스 샌드위치: 15.5(메인 메뉴)(밀가루, 양파, 신선한 돼지고기, 바다 소금)
* 바삭한 코코넛 쿠키 마끼아또: 16(음료)(커피 원두, 우유, 푸카 쿠키, 코코넛)
* 눈 덮인 말차 라떼: 16.5(음료)(커피 원두, 우유, 휘핑크림, 말차 가루)
* 티라미수: 17(디저트)(밀가루, 푸카 쿠키, 치즈 덩이, 커피 원두)
* 햄 치즈 크루아상: 17.5(메인 메뉴)(밀가루, 상추, 햄, 치즈 덩이)
* 캐러맬 초코 크레이프: 18(디저트)(밀가루, 휘핑크림, 백설탕, 코코아 가루)
