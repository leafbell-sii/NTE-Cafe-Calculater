# 게임 내부정보 정리

## 1. 기본 시스템
- 가게 구조
    1. 5개 지점 (푸른 수염길점, 바로크 거리점, 스위트 피어 거리점, 무민 거리점, 반각 거리점)
        - **5개 지점은 형식상의 표현일 뿐이며, 계산에서는 가게 구분을 하지 않는다.**
        - 유동인구, 인기도, 직원 버프, 음식 등 모든 값은 전체 공용값 하나로 취급한다.
        - 따라서 최종 수익은 가게별 합산이 아니라 아래 「계산 로직」의 계산식 하나로 끝난다.
    2. 배치 가능한 직원 수: 최대 10명 (형식상 가게당 2명)
        - 빈 자리를 둘 수 있다.
        - 한 캐릭터는 한 번만 배치할 수 있다.
    3. 배치 가능한 음식 수: 최대 5개
        - 같은 음식은 한 번만 넣을 수 있다.
    4. 최종 수익: 시간당 폰즈로 계산됨

- 용어
    1. 폰즈: 기본 화폐 단위
    2. 기본 유동인구(트래픽)(기본값: 2400p): 계산의 매개변수 (단위: p, 포인트). 공용값.
    3. 유동인구
        - 직원 버프가 반영된 최종 유동인구.
        - 정의: `((기본 유동인구) + (유동인구 합연산 버프)) * (유동인구 곱연산 버프)`
    4. 유동인구 합연산 버프
        - 유동인구에 P 단위로 더해지는 모든 버프
        - 정의: `(버프1) + (버프2) + ...`
    5. 유동인구 곱연산 버프
        - 유동인구에 % 단위로 곱해지는 모든 버프
        - 정의: `1 + (버프1) + (버프2) + ...`
    6. 유동인구 계수
        - 실제 계산에 사용되는 계수.
        - 정의: `(유동인구) / 100`
    7. 음식 계수(음식1)
        - 실제 계산에 사용되는 단일 음식 계수.
        - 정의: `((음식1 가격) + (트렌드 계수) + (합연산 버프)) * (곱연산 버프)`
        - 합연산 버프는 음식마다 각각 더해진다. (예: +0.12폰즈 버프는 음식 5개에 각각 붙어 총 +0.6폰즈 효과)
    8. 총 음식 계수
        - 실제 계산에 사용되는 음식 계수의 총합
        - 정의: `(음식 계수(음식1) + 음식 계수(음식2) + 음식 계수(음식3) + 음식 계수(음식4) + 음식 계수(음식5))`
    9. 인기도 계수(기본값: 0)
        - 게임 내 시스템. 사용자 입력으로 받음(ex: 0.015). 공용값.
    10. 최종 인기도 계수
        - 최종으로 곱해지는 계수
        - 정의: `1 + (인기도 계수)`
    11. 합연산 버프 (판매가)
        - 음식에 합연산으로 적용되는 모든 버프 (폰즈 단위)
        - 정의: `(버프1) + (버프2) + ...`
    12. 곱연산 버프 (판매가)
        - 음식에 곱연산으로 적용되는 모든 버프 (% 단위)
        - 정의: `1 + (버프1) + (버프2) + ...`
    13. 트렌드 계수
        - 현재 트렌드에 해당하는 음식에만 적용되는 버프.
        - 정의: 해당 음식이면 `0.75`, 아니면 `0`

## 2. 트렌드
- 트렌드는 한 번에 하나만 활성화된다. (한 음식에 트렌드 계수가 중복 적용되는 경우는 없음)
- 종류
    1. 태그 트렌드 (메인 메뉴 / 디저트 / 음료): 해당 태그를 가진 음식에 적용
    2. 재료 트렌드
        - 과일(코코넛/사과/토마토/오렌지/딸기): 과일 재료가 하나라도 들어간 음식에 적용
        - 그 외 각 재료명: 해당 재료가 들어간 음식에 적용

## 3. 도시 스킬 적용 규칙
- 스킬 레벨 효과는 누적된다. (레벨 5 = 레벨 1~5 효과 모두 적용)
- 스킬 조건의 「진열된 메뉴」는 공용 메뉴 5개 전체를 뜻한다.
- 「태그가 N개 붙어있으면/경우」는 **N개 이상**을 뜻한다.
- 「태그가 N개 붙어있을 때마다」도 **N개 이상이면 1회만** 적용한다. (개수에 비례해 반복 적용하지 않음)
- 같은 캐릭터의 서로 다른 레벨 효과는 조건이 같아도 각각 적용된다. (예: 신쿠 Lv1 + Lv3 = 0.6폰즈)
- 계산에서 제외하는 효과
    - 식재료 소모속도 감소
    - 「점장 특제」 관련 효과

## 4. 계산 로직
- 최종 수익 계산: `(총 음식 계수) * (유동인구 계수) * (최종 인기도 계수)`
