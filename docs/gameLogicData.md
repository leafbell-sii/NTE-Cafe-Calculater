# 게임 로직 규칙

- 게임 내 규칙과 계산식을 정리한 문서. 실제 수치 데이터는 `src/data/*.json`에 있다. (데이터 구성은 `SPEC.md` 「데이터」 항목 참고)
- 표기: % 단위 값은 모두 소수로 표기한다. (1% = 0.01)

## 1. 기본 시스템
- 가게 구조
    1. 5개 지점 (푸른 수염길점, 바로크 거리점, 스위트 피어 거리점, 무민 거리점, 반각 거리점)
        - **5개 지점은 형식상의 표현일 뿐이며, 계산에서는 가게 구분을 하지 않는다.**
        - 유동인구, 인기도, 직원 버프, 음식 등 모든 값은 전체 공용값 하나로 취급한다.
        - 따라서 최종 수익은 가게별 합산이 아니라 아래 「계산 로직」의 계산식 하나로 끝난다.
    2. 배치 가능한 직원 수: 최대 10명 (형식상 가게당 2명)
        - 빈 자리를 둘 수 있다.
        - 한 캐릭터는 한 번만 배치할 수 있다.
    3. 배치 가능한 음식 수: 최대 5개
        - 빈 자리를 둘 수 있다.
        - 같은 음식은 한 번만 넣을 수 있다.
    4. 최종 수익: 시간당 폰즈로 계산됨

- 용어
    1. 폰즈: 기본 화폐 단위
    2. 기본 유동인구(트래픽)(기본값: 2400p): 계산의 매개변수 (단위: p, 포인트). 공용값.
    3. 유동인구
        - 직원 버프가 반영된 최종 유동인구.
        - 정의: `((기본 유동인구) + (유동인구 합연산 버프)) * (1 + (유동인구 곱연산 버프))`
    4. 유동인구 합연산 버프
        - 유동인구에 P 단위로 더해지는 모든 버프의 합
        - 정의: `(버프1) + (버프2) + ...`
    5. 유동인구 곱연산 버프
        - 유동인구에 % 단위로 곱해지는 모든 버프의 합 (1은 포함하지 않음)
        - 정의: `(버프1) + (버프2) + ...`
    6. 유동인구 계수
        - 실제 계산에 사용되는 계수.
        - 정의: `(유동인구) / 100`
    7. 음식 계수(음식1)
        - 실제 계산에 사용되는 단일 음식 계수.
        - 정의: `((음식1 가격) + (트렌드 계수) + (판매가 합연산 버프)) * (1 + (판매가 곱연산 버프))`
        - 판매가 합연산 버프는 음식마다 각각 더해진다. (예: +0.12폰즈 버프는 음식 5개에 각각 붙어 총 +0.6폰즈 효과)
        - 트렌드 계수에도 판매가 곱연산 버프가 적용된다.
    8. 총 음식 계수
        - 진열된 모든 음식의 음식 계수 합 (최대 5개, 빈 자리는 0)
        - 정의: `(음식 계수(음식1)) + (음식 계수(음식2)) + ... + (음식 계수(음식5))`
    9. 인기도 계수(기본값: 0)
        - 게임 내 시스템. 사용자 입력으로 받음. 공용값.
        - 게임 표기와 같은 소수로 입력한다. (예: 0.015)
    10. 최종 인기도 계수
        - 최종으로 곱해지는 계수
        - 정의: `1 + (인기도 계수)`
    11. 판매가 합연산 버프
        - 음식에 합연산으로 적용되는 모든 버프의 합 (폰즈 단위)
        - 정의: `(버프1) + (버프2) + ...`
    12. 판매가 곱연산 버프
        - 음식에 곱연산으로 적용되는 모든 버프의 합 (% 단위, 1은 포함하지 않음)
        - 정의: `(버프1) + (버프2) + ...`
    13. 트렌드 계수
        - 현재 트렌드에 해당하는 음식에만 적용되는 버프.
        - 정의: 해당 음식이면 태그 트렌드는 `1.00`, 그 외 트렌드(과일·재료)는 `0.75`, 아니면 `0`

## 2. 음식
- 음식은 이름, 가격(폰즈), 태그, 재료 목록을 가진다.
- 태그는 `메인 메뉴` / `디저트` / `음료` 중 하나이며, 음식당 하나만 가진다.
- 음식 이름은 게임 내 원문 표기를 따른다. (예: 「캐러맬 초코 크레이프」는 원문 표기)

## 3. 트렌드
- 게임에서는 항상 하나의 트렌드가 활성화되어 있다.
    - 단, 계산기에서는 「없음」도 선택할 수 있다. (기본값: 없음)
- 트렌드는 한 번에 하나만 활성화된다.
- 종류
    1. 태그 트렌드 (메인 메뉴 / 디저트 / 음료): 해당 태그를 가진 음식에 적용
    2. 과일 트렌드: 과일 재료가 하나라도 들어간 음식에 적용
        - 과일 재료 목록은 `src/data/trends.json`에 있다.
    3. 재료 트렌드: 모든 재료 각각이 트렌드가 될 수 있으며, 해당 재료가 들어간 음식에 적용
        - 과일 재료도 포함한다. (예: 「사과」 트렌드는 사과가 들어간 음식에만 적용)
- **트렌드 계수는 한 음식에 최대 1회만 적용된다.**
    - 과일 트렌드에서 과일 재료가 여러 개 들어간 음식도 1회만 적용한다. (예: 뜨거운 오렌지 커피는 오렌지·사과가 모두 들어있지만 `+0.75` 한 번)

## 4. 도시 스킬 적용 규칙
- 캐릭터마다 레벨 1~5의 도시 스킬이 있으며, 계산에 쓰이는 효과는 4종류다.
    1. 판매가 합연산 (폰즈)
    2. 판매가 곱연산 (%)
    3. 유동인구 합연산 (P)
    4. 유동인구 곱연산 (%)
- 스킬 레벨 효과는 누적된다. (레벨 5 = 레벨 1~5 효과 모두 적용)
- 스킬 원문의 「배치된 가게」, 「해당 가게」는 가게 구분 없이 전체에 적용한다. (「기본 시스템」 참고)
- 스킬 조건의 「진열된 메뉴」는 공용 메뉴 5개 전체를 뜻한다.
- 「태그가 N개 붙어있으면/경우」는 **N개 이상**을 뜻한다.
- 「태그가 N개 붙어있을 때마다」도 **N개 이상이면 1회만** 적용한다. (개수에 비례해 반복 적용하지 않음)
- 같은 캐릭터의 서로 다른 레벨 효과는 조건이 같아도 각각 적용된다. (예: 신쿠 Lv1 + Lv3 = 0.6폰즈)
- 계산에서 제외하는 효과
    - 식재료 소모속도 감소
    - 「점장 특제」 관련 효과

## 5. 계산 로직
- 최종 수익 계산: `(총 음식 계수) * (유동인구 계수) * (최종 인기도 계수)`
