# 게임 내부정보 정리

## 1. 기본 시스템
- 가게 구조
    1. 5개 지점 (푸른 수염길점, 바로크 거리점, 스위트 피어 거리점, 무민 거리점, 반각 거리점)
        - 가게별 차이는 존재 x. ui 차원에서만 고려
    2. 배치 가능한 직원 수: 10 (가게당 2)
    3. 배치 가능한 음식 수: 5 (가게별로 배치 아님. 즉, 특정 가게에서 버프가 적용된다면 다른 모든 가게에도 적용됨.)
    4. 최종 수익: 시간당 폰즈로 계산됨

- 용어
    1. 폰즈: 기본 화폐 단위
    2. 유동인구(트래픽)(기본값: 2400p): 계산의 매개변수 (단위: p, 포인트)
    3. 유동인구 계수
        - 실제 계산에 사용되는 계수.
        - 정의: `(유동인구) / 100`
    4. 음식 계수(음식1)
        - 실제 계산에 사용되는 단일 음식 계수.
        - 정의: `((음식1) + (트렌드 계수) + (합연산 버프)) * (곱연산 버프)`
    5. 총 음식 계수
        - 실제 계산에 사용되는 음식 계수의 총합
        - 정의: `(음식 계수(음식1) + 음식 계수(음식2) + 음식 계수(음식3) + 음식 계수(음식4) + 음식 계수(음식5))`
    6. 인기도 계수(기본값: 0)
        - 게임 내 시스템. 사용자 입력으로 받음(ex: 0.015)
    7. 최종 인기도 계수
        - 최종으로 곱해지는 계수
        - 정의: `1 + (인기도 계수)`
    8. 합연산 버프
        - 음식에 합연산으로 적용되는 모든 버프
        - 정의: `(버프1) + (버프2) + ...`
    9. 곱연산 버프
        - 음식에 곱연산으로 적용되는 모든 버프
        - 정의: `1 + (버프1) + (버프2) + ...`
    10. 트렌드 계수
        - 해당하는 음식에만 적용되는 버프.
        - 정의: `0.75`

## 2. 계산 로직
- 최종 수익 계산: (총 음식 계수) * (유동인구 계수) * (최종인기도 계수)
